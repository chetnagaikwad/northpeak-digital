# NorthPeak Digital — build a one-page agency site

A responsive, high-performance one-page landing page built for NorthPeak Digital as part of the Digital Heroes Internship Qualification Assessment.

##  Quick Links
- **Live Demo:** [https://chetnagaikwad.github.io/northpeak-digital/](https://chetnagaikwad.github.io/northpeak-digital/)
- **Repository:** [https://github.com/chetnagaikwad/northpeak-digital](https://github.com/chetnagaikwad/northpeak-digital)

##  Tech Stack
- Vanilla HTML5 (Semantic Structure)
- Custom CSS (Flexbox/Grid, Dark Mode Glassmorphism)
-  JavaScript (Form Validation & Mobile Navigation)

##  Features
- **Hero Section:** Headline & CTA button.
- **Services Grid:** Showcase of 6 core agency offerings.
- **Testimonials & Pricing:** 3-tier pricing structure.
- **Contact Form:** Client-side validation.
- **Performance:** 90+ Lighthouse score on Performance & Accessibility.
